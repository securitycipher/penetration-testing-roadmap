# BTL1 (Blue Team Level 1)

BTL1 from Security Blue Team is a **defensive** certification - SIEM, log analysis, incident response. Pentesters benefit from blue team skills for detection evasion awareness and career flexibility.

## What it covers

- Log analysis (Splunk, Windows Event IDs)
- Network traffic analysis (Wireshark)
- Phishing and malware triage
- Incident response lifecycle
- Threat intelligence basics

## Why pentesters take it

- Understand what defenders see when you attack
- Pivot to SOC analyst or purple team roles
- Complements OSCP for well-rounded security profile

## Exam format

- 24-hour practical with SIEM access
- Analyze logs, write incident report, answer technical questions
