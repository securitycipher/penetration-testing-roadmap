# OSED (Offensive Security Exploit Developer)

OSED is OffSec's **Windows exploit development** cert. It is for people who want to go deeper than using public exploits and actually write their own. It is one of the three certs in the OSCE3 bundle (with OSWE and OSEP).

## Course and exam

- Course: **EXP-301** (Windows User Mode Exploit Development)
- Exam: **47 hours 45 minutes** hands-on, then 24 hours to report
- 32-bit Windows user-mode focus

## What it covers

- Stack buffer overflows and crafting shellcode
- **Bypassing DEP** with ROP (return-oriented programming)
- **Defeating ASLR**
- Reverse engineering with WinDbg and IDA
- Format string bugs and custom shellcode encoders

## Prerequisites

- Comfortable with assembly and a debugger
- Basic C and scripting (Python) ability
- Patience - this is a slow, detail-heavy discipline

## How to prepare

- EXP-301 labs end to end
- Practice with vulnerable Windows binaries and public CVE reproductions
- Related reading: [Buffer Overflow](../Vulnerabilities/Buffer%20Overflow.md)
