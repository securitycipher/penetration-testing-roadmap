# CompTIA Security+ (SY0-701)

Security+ is the baseline, vendor-neutral security cert. It is not offensive, but it clears HR filters, maps to DoD 8140 baselines, and proves you understand the fundamentals employers assume. The current exam is **SY0-701**.

## Exam format

- Up to **90 questions** (multiple choice + performance-based), 90 minutes
- Scored 100-900, passing is **750**
- Valid for 3 years; renew with continuing education

## The five SY0-701 domains

1. **General Security Concepts** - controls, zero trust, cryptography basics
2. **Threats, Vulnerabilities, and Mitigations** - attack types, indicators, hardening
3. **Security Architecture** - secure design, cloud, resilience, data protection
4. **Security Operations** - monitoring, incident response, vuln management, IAM
5. **Security Program Management and Oversight** - governance, risk, compliance, third-party risk

(SY0-701 trimmed the old six SY0-601 domains to five and added more cloud, zero trust, and automation content.)

## Who it is for

- Career switchers and students who need a recognized first cert
- SOC, helpdesk, and sysadmin roles moving toward security
- A foundation layer before offensive certs like eJPT or PenTest+
