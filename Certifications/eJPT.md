# eJPT (eLearnSecurity Junior Penetration Tester)

eJPT is an entry-level, fully hands-on pentest cert. It is now run by **INE Security** (the eLearnSecurity brand was folded into INE), and the current exam is **eJPT v2**.

## Exam format

- 100% practical, performance-based lab (no multiple choice theory dump)
- **48 hours**, scenario-based: you answer dynamic questions by actually hacking the lab
- Open-book, open-internet, like a real engagement
- No formal report required (that is what PNPT adds later)

## What it covers

- Assessment methodology and basic recon
- Network scanning and enumeration with Nmap
- Host and network attacks, basic pivoting
- Web application basics (SQLi, directory enumeration)
- Metasploit and manual exploitation fundamentals

## Who it is for

- Complete beginners who want a first practical cert
- Students validating the INE PTS / "Penetration Testing Student" path
- A confidence builder before PNPT or OSCP

## How to prepare

- Work the free/low-cost INE **Penetration Testing Student** learning path
- Practice on [TryHackMe](../Labs/TryHackMe.md) beginner rooms and easy [HackTheBox](../Labs/HackTheBox.md) boxes

- **eJPT** - easiest practical on-ramp, no report
- **PNPT** - network + AD + a real report
- **OSCP+** - harder, more prestige
