# BSCP (Burp Suite Certified Practitioner)

BSCP from PortSwigger is a focused, affordable **web application** cert tied directly to the free [Web Security Academy](../Labs/Web%20Security%20Academy.md). It proves you can find and exploit modern web bugs with Burp Suite, and it is one of the best value-for-money web certs available.

## Exam format

- **Practical, browser-based**, 4 hours
- Two randomly selected web apps; for each you must:
  1. Find and exploit a vulnerability to reach a lower-privileged account
  2. Escalate to admin
  3. Read a protected file / retrieve the flag
- You need to solve both apps fully to pass

## What it covers

- The full breadth of the Web Security Academy topics
- SQLi, XSS, SSRF, access control, auth, deserialization, request smuggling, and more
- Efficient use of Burp Suite (Repeater, Intruder, extensions)
- Working fast under time pressure

## Who it is for

- Bug bounty hunters and web-focused testers
- Anyone who finished the Web Security Academy and wants proof
- A strong, cheaper stepping stone toward OSWE

## How to prepare

- Complete **all** [Web Security Academy](../Labs/Web%20Security%20Academy.md) labs, including "mystery" lab practice
- Drill the mock exam until you can finish well inside the time limit
