# eMAPT (Mobile Application Penetration Tester)

eMAPT from **INE Security** (formerly eLearnSecurity) is a hands-on **mobile application** pentest cert. It is one of the few practical mobile certs and is useful if you want to specialize in Android and iOS testing.

## Exam format

- Practical, project-style: you are given a task to **develop a working exploit / vulnerable-app analysis** and submit your work
- No multiple choice; you prove skill by producing results
- Focused heavily on Android, with iOS concepts

## What it covers

- Android app architecture, APK structure, and reversing
- Insecure data storage, IPC, and exported components
- Intercepting and tampering with mobile traffic
- Bypassing root/jailbreak detection and basic obfuscation
- Dynamic instrumentation with **Frida** and static analysis with MobSF

## Who it is for

- Testers specializing in mobile
- App security engineers validating hands-on skill
- Related reading: [Android Security Testing](../Mobile/Android%20Security%20Testing.md), [iOS Security Testing](../Mobile/iOS%20Security%20Testing.md)

## How to prepare

- INE Mobile Application Security / Penetration Testing path
- Practice on intentionally vulnerable apps (DIVA, InsecureBankv2, OWASP MSTG crackmes)
