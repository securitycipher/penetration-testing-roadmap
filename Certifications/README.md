# Certifications - overview and paths

Certs do not make you a pentester, but they open doors, clear HR filters, and give you a goal to study toward. Prices and exam formats change often - always confirm on the vendor site before you buy. Treat the ranges below as rough guidance.

## Which cert, by goal

- **Just starting, need a resume line:** [CC](CC.md) (often free), then [Security+](CompTIA%20Security%2B.md)
- **First practical / hands-on win:** [eJPT](eJPT.md) or [PJPT](PJPT.md)
- **Internal network + Active Directory pentest:** [PNPT](PNPT.md) -> [CRTP](CRTP.md) -> [CRTE](CRTE.md)
- **General offensive benchmark:** [OSCP+](OSCP.md) or [CPTS](CPTS.md)
- **Web app / bug bounty depth:** [BSCP](BSCP.md) -> [OSWE](OSWE.md)
- **Red teaming / evasion:** [CRTO](CRTO.md) or [OSEP](OSEP.md)
- **Cloud (Azure/Entra):** [CARTP](CARTP.md)
- **Mobile:** [eMAPT](eMAPT.md)
- **Exploit development:** [OSED](OSED.md)
- **Blue / purple team:** [BTL1](BTL1.md) or [CDSA](CDSA.md)
- **AI / LLM security:** [AI / ML Pentester](AI-ML%20Pentester.md)

## Honest advice

- One strong practical cert plus public writeups beats a wall of multiple-choice certs.
- Do not pay full price for OffSec courses if a cheaper path (CPTS, CRTP, BSCP) matches your goal.
- Employers care about the skills behind the cert. Keep a [HackTheBox](../Labs/HackTheBox.md) / [TryHackMe](../Labs/TryHackMe.md) profile and a blog going alongside.
