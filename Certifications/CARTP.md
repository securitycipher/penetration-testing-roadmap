# CARTP (Certified Azure Red Team Professional)

CARTP from **Altered Security** is a hands-on **Azure / Entra ID red team** cert. As enterprises move identity to the cloud, attacking Entra ID (formerly Azure AD) and hybrid setups has become a core pentest skill, and CARTP is the go-to practical cert for it.

## What it covers

- Entra ID (Azure AD) enumeration and recon
- Phishing and initial access into cloud tenants
- Abusing **managed identities**, service principals, and app registrations
- Privilege escalation across Azure roles (RBAC) and directory roles
- **Hybrid attacks**: on-prem AD to cloud and back (PHS, PTA, federation abuse)
- Persistence in Azure and consent/OAuth abuse

## Exam format

- **24-hour** hands-on lab exam, then 48 hours to submit the report
- Compromise the Azure/hybrid environment and document the attack path

## Prerequisites

- Basic [Active Directory](../Active%20Directory/Active%20Directory%20Basics.md) and [Azure](../Cloud/Azure.md) knowledge
- Comfort with PowerShell and cloud CLIs

## How to prepare

- Altered Security's Azure course labs
- Practice with free tooling: ROADtools, AzureHound, MicroBurst
