# WebVerse Labs

WebVerse Labs is a platform focused entirely on **web application security**. It combines single-vulnerability challenges, multi-service labs that chain exploits across a realistic application stack, and large multi-site ranges, with a free academy for fundamentals. The emphasis is on realistic, business-logic-driven targets rather than isolated test pages, which helps bridge the gap between learning a vulnerability class and exploiting it in a believable application.

## What it is good at

- Single-vulnerability challenges for drilling one class at a time (SQLi, SSRF, [XXE](../Vulnerabilities/XXE.md), JWT, access control, business logic)
- Multi-service labs that chain bugs across services, closer to a real engagement
- Large multi-site ranges that model a whole company estate
- 100% web focus - no Active Directory or binary exploitation, so the learning stays on application security

## How to use it

1. Start with the free academy and the single-vulnerability challenges to build fundamentals.
2. Move to the multi-service labs to practice chaining bugs across an application.
3. Work the ranges once you want a full-estate, multi-site target.

Good preparation for web-focused certifications like [BSCP](../Certifications/BSCP.md) and [OSWE](../Certifications/OSWE.md).
